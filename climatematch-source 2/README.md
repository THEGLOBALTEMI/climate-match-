# ClimateMatch

AI-powered climate career matching platform.

## Quick start

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this repo to GitHub
2. Import in Vercel — it auto-detects Vite
3. Click Deploy

## Build

```bash
npm run build   # outputs to dist/
```
